I’m a Computer Science graduate from the University of Texas at El Paso, and I’m currently working as a Junior Data Analyst at Steampunk. My work focuses on building interactive dashboards, automating reporting workflows, and turning messy data into actionable insights.

I enjoy creating software projects that blend problem-solving with practical tools — from data automation and dashboarding to Java apps, Python scripts, networking experiments, and small browser games. Outside of work, I like hiking, cycling, morning workouts, and going to live concerts.
